One image summing up the world's news of Monday 23 November 2026, drawn
procedurally with Python (PIL) — no network, no randomness, deterministic:
every run writes the same bytes to `/output/entry.png`.

Stories in the image: COP31 climate deal collapses over the fossil-fuel
phase-out (lead); tankers attacked in the Strait of Hormuz; Democrats win
the US Congress; cartel chief Chapo Isidro arrested; Ukrainian drones hit
a Russian warship off Benghazi. No human or animal faces anywhere.

## Run

```sh
python3 main.py
```

Writes `/output/entry.png` (1024x1024 PNG, under 1 MiB).
